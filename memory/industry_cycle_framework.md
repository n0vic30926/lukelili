## 二、当前全局判断（2026年5月）

**AI产业 = 基础设施建设中后期 + 应用层商业化早期 + 泡沫争议升温期**

- **上半场（已过）**：建基础设施——GPU/数据中心/模型训练，资本密集投入
- **中场（当前）**：推理需求超越训练，资本开支见顶争议出现，存储短缺加剧，应用层开始探索商业化
- **下半场（未到）**：应用层真正兑现收入，基础设施开始整合

**关键风险信号**：
1. 应用层收入缺口$6000亿（红杉估算）
2. 循环交易推高账面收入（英伟达→OpenAI→微软→英伟达）
3. 产业链债务激增（2025年$1218亿+531%）
4. AI裁员替代螺旋（2026年Q1占裁员13%）
5. 纳指PE/PB突破十年危险值，风险溢价为负
